Вступ до текстової стеганографії

Визначення

Текстова стеганографія — це форма прихованої комунікації, яка приховує секретну інформацію в тексті природної мови, роблячи існування прихованого повідомлення невиявленим для сторонніх спостерігачів.

Особливості та виклики

Текстова стеганографія є найскладнішим видом стеганографії через особливості текстових даних:

Аспект Зображення Аудіо Текст
Надлишковість Висока (LSB) Середня Дуже низька
Ємність ~1 біт/піксель Варіює ~0.5-2 біт/речення
Детекція Статистичний аналіз Спектральний аналіз Лінгвістичний аналіз
Робастність Помірна Добра Низька-середня

Ключовий виклик

Текстові файли містять мінімальну надлишкову інформацію для приховування секретних даних. Модифікації легше виявляються людиною, а зміни повинні зберігати семантичну та синтаксичну коректність.

Історичні методи

Null Cipher (Нуль-шифр)

Null cipher — це стародавня форма стеганографії, де відкритий текст змішаний з нешифрованим матеріалом. Читач повинен відкинути певні символи, щоб виявити повідомлення.

Приклад з Першої світової війни

"PRESIDENT'S EMBARGO RULING SHOULD HAVE IMMEDIATE NOTICE." Перші літери: P-E-R-S-H-I-N-G (Генерал Pershing)

Типи правил null cipher:

  • Перша літера кожного слова
  • Остання літера кожного слова
  • Кожна n-та літера
  • Перша літера кожного другого слова

Акростих

Акростих — розширена форма null cipher, де повідомлення приховано в перших літерах (або інших позиціях) рядків вірша чи тексту.

Історичне використання

  • Таємні образи могутніх осіб
  • Кодування повідомлень у опублікованих творах
  • Релігійні та містичні тексти

Шифр Бекона (1605)

Білітеральний шифр Френсіса Бекона — один з найраніших систематичних стеганографічних методів.

Таблиця кодування

A = AAAAA N = ABBAB B = AAAAB O = ABBBA C = AAABA P = ABBBB D = AAABB Q = BAAAA E = AABAA R = BAAAB ...

Стеганографічна реалізація:

  • Використовуються два шрифти (наприклад, звичайний та курсив)
  • Звичайний = A, Курсив = B
  • Кожна літера потребує 5 символів cover-тексту
Довжина cover-тексту = Довжина повідомлення × 5

Форматні методи

Маніпуляція пробілами (Whitespace)

Найпоширеніший підхід використовує комбінації пробілів та табуляцій для кодування бінарних даних:

Базове кодування

Пробіл = 0 Табуляція = 1 Приклад: "Hello World" + приховане "A" (ASCII 65 = 01000001) "Hello[space][tab][space][space][space][space][space][tab]World"

Інструмент SNOW

SNOW — популярний інструмент whitespace стеганографії:

  • Додає послідовності до 7 пробілів з табуляціями в кінці рядків
  • Зазвичай дозволяє зберігати 3 біти на 8 колонок
  • Підтримує ICE шифрування для додаткової безпеки

Маніпуляція закінченнями рядків

Різні операційні системи використовують різні закінчення рядків:

Windows: \r\n (CR+LF) Unix/Linux: \n (LF) Classic Mac: \r (CR)

Змішуючи їх, можна кодувати бінарні дані (2 біти на рядок).

Вразливості whitespace методів

  • Текстові редактори можуть нормалізувати пробіли
  • Copy-paste часто видаляє trailing spaces
  • Email системи можуть переформатувати текст

Unicode стеганографія

Zero-Width символи

Unicode містить кілька символів нульової ширини, які невидимі при відображенні:

Символ Unicode Назва Ширина
ZWSP U+200B Zero Width Space 0
ZWNJ U+200C Zero Width Non-Joiner 0
ZWJ U+200D Zero Width Joiner 0
WJ U+2060 Word Joiner 0
FEFF U+FEFF Zero Width No-Break Space 0

Алгоритм кодування

Просте 2-символьне кодування (1 біт на символ)

def encode_binary(message, cover_text): binary = ''.join(format(ord(c), '08b') for c in message) encoded = "" for bit in binary: if bit == '0': encoded += '\u200B' # ZWSP else: encoded += '\u200C' # ZWNJ # Вставляємо в середину cover-тексту mid = len(cover_text) // 2 return cover_text[:mid] + encoded + cover_text[mid:]
Ємність (біти) = len(cover_text) × біти_на_позицію

Переваги Unicode методів

  • Повністю невидимі для людини
  • Текст виглядає абсолютно нормально
  • Проста реалізація

Обмеження

  • Деякі платформи видаляють zero-width символи
  • Можуть бути виявлені аналізом символів
  • Не підходять для критичних застосувань без шифрування

HTML/CSS стеганографія

Маніпуляція регістром тегів

HTML теги нечутливі до регістру, що дозволяє бінарне кодування:

<!-- Оригінал --> <HTML><BODY><P>Text</P></BODY></HTML> <!-- З прихованим "10" --> <html><BODY><P>Text</P></BODY></html> lowercase = 0, uppercase = 1

Перестановка атрибутів

HTML атрибути можуть з'являтися в будь-якому порядку:

<!-- Прихований біт 0 --> <img src="image.jpg" alt="photo" width="100"> <!-- Прихований біт 1 (атрибути переставлені) --> <img alt="photo" src="image.jpg" width="100">

Ємність: 1 біт на тег з 2+ атрибутами, що можна переставляти.

CSS-based приховування

/* Приховані дані в порядку властивостей або значеннях */ .class { color: #000001; /* Останній біт кодує дані */ margin: 10px 10px; /* Надлишкові значення для приховування */ }

Переваги HTML методів

HTML стеганографія має перевагу збереження при передачі через web, оскільки браузери нормалізують багато аспектів HTML, але зберігають структуру.

Лінгвістичні методи

Заміна синонімів

Принцип: Заміна слів семантично еквівалентними синонімами для кодування бітів.

Приклади пар слів (1 біт кожна)

big / large → 0/1 small / tiny → 0/1 fast / quick → 0/1 happy / glad → 0/1

Алгоритм вершинного кодування (Chang & Clark)

  1. Побудувати граф, де слова — вершини
  2. З'єднати синоніми ребрами
  3. Призначити бінарні коди через розфарбування графа
  4. Замінити слова відповідно до секретних бітів

Ємність вбудовування: приблизно 0.67 біт на речення.

Складнощі синонімічних методів

  • Контекстно-залежні значення слів
  • Не всі синоніми взаємозамінні
  • Зміни статистичного розподілу виявляються
  • Потребують NLP інструментів

Синтаксичні трансформації

Маніпуляція структурою речення зі збереженням значення:

Типи трансформацій

Актив → Пасив: "Кіт зловив мишу" → "Миша була зловлена котом" (0 → 1) Cleft речення: "Іван з'їв торт" → "Це Іван з'їв торт" (0 → 1) Порядок прикметників: "гарний великий будинок" → "великий гарний будинок" (0 → 1)

Ємність: 0.5-1.0 біт на речення.

Семантичні методи

Найскладніший підхід — маніпуляція значенням на концептуальному рівні:

  • Генерація парафраз
  • Переупорядкування інформації
  • Модифікація структури дискурсу
  • Вставка пресупозицій

Поточні обмеження

Семантичні методи непрактичні з поточними NLP технологіями для надійної автоматичної реалізації.

Нейронні мережі в текстовій стеганографії

RNN-Stega

Архітектура: Рекурентна нейронна мережа, навчена на великих текстових корпусах.

Процес

  1. Навчити RNN мовну модель на текстовому корпусі
  2. На кожному кроці генерації модель передбачає розподіл ймовірностей по словнику
  3. Секретні біти вибирають з кандидатів на основі ймовірностей
P(wt | w1, ..., wt-1) = RNN(context)
bits_embedded = log2(|candidates|)

Adaptive Dynamic Grouping (ADG)

Алгоритм

  1. На кожному часовому кроці отримати розподіл ймовірностей по словнику
  2. Динамічно розділити словник на 2r груп з рівною загальною ймовірністю
  3. Кожна група представляє r-бітовий сегмент повідомлення
  4. Вибрати з нормалізованого розподілу вибраної групи

Ємність: r бітів на згенерований токен.

Безпека: Доказово безпечний за метрикою KL-дивергенції.

LLM-based стеганографія (2024)

LLM-Stega для black-box API доступу:

Компоненти

  1. Побудова ключових слів: створення keywords з секретного повідомлення
  2. Зашифроване стеганографічне відображення: mapping повідомлення на елементи промпту
  3. Генерація стего-тексту: використання LLM для генерації cover-тексту
  4. Витягування повідомлення: зворотне відображення зі згенерованого тексту

Ключова інновація

Працює з користувацькими інтерфейсами LLM (GPT, Claude, LLaMA) без потреби в доступі до ваг моделі.

Стегоаналіз тексту

Виявлення whitespace стеганографії

def detect_whitespace_stego(text): # Підрахунок trailing whitespace на рядок trailing_ws = [len(line) - len(line.rstrip()) for line in text.split('\n')] # Статистичний аналіз avg_trailing = sum(trailing_ws) / len(trailing_ws) variance = sum((x - avg_trailing)**2 for x in trailing_ws) / len(trailing_ws) # Флаг якщо виявлено незвичні патерни if avg_trailing > 3 or variance > 10: return "Підозріло: можлива whitespace стеганографія" return "Чисто"

Виявлення zero-width символів

import re def detect_zwc(text): zwc_pattern = r'[\u200B\u200C\u200D\u2060\uFEFF]' matches = re.findall(zwc_pattern, text) if matches: return f"Виявлено {len(matches)} zero-width символів" return "Zero-width символи не знайдено"

Статистичний аналіз

Детекція на основі перплексії

Perplexity = exp(-1/N × Σ log P(wi | context))

Вища перплексія в стего-тексті вказує на неприродний вибір слів.

Feature вектори для ML детекції

  1. Розподіл частот слів
  2. N-gram статистики
  3. Варіація довжини речень
  4. Розподіл POS-тегів
  5. Патерни пунктуації

Машинне навчання детекторів

Deep Learning архітектури

CNN-based:

Input → Word Embedding → Conv1D (varying kernels) → MaxPool → Dense → Output

LSTM-based:

Input → Embedding → BiLSTM → Attention → Dense → Output

BERT-based detection:

  • Fine-tune BERT на класифікації cover/stego тексту
  • Використовує попередньо навчене розуміння мови
  • State-of-the-art продуктивність

Метрики детекції

Accuracy = (TP + TN) / (TP + TN + FP + FN)

Precision = TP / (TP + FP)

Recall = TP / (TP + FN)

F1 = 2 × (Precision × Recall) / (Precision + Recall)

Практичні застосування

Легітимні використання

  • Захист авторських прав: вбудовування інформації про власність
  • Відстеження документів: ідентифікація джерела витоків
  • Автентифікація контенту: перевірка цілісності документа
  • Водяні знаки: невидимі підписи в тексті

Чотири стовпи текстової стеганографії

  1. Ємність (C): Максимальна кількість вбудовуваних бітів
  2. Непомітність (I): Невиявлюваність людиною
  3. Безпека (S): Невиявлюваність алгоритмами
  4. Робастність (R): Виживання після модифікацій

Ключові висновки

  • Текстова стеганографія — найскладніший вид через низьку надлишковість
  • Форматні методи прості, але вразливі до переформатування
  • Лінгвістичні методи робастніші, але потребують NLP
  • Нейронні методи — найперспективніший напрям
  • Стегоаналіз активно розвивається разом з методами приховування
